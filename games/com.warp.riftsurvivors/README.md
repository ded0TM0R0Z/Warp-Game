# Rift Survivors

Первая игра для WARP GAME. 2D survival arena, Phaser 3.90.0, горизонтальная ориентация.

## Управление
- Левый виртуальный стик — движение.
- Кнопка рывка справа — короткое ускорение с перезарядкой.
- Атака происходит автоматически по ближайшему противнику.
- При повышении уровня выбери одно из трёх улучшений.

## Сборка
Все зависимости находятся в пакете. Сеть для игры не требуется.
Публикация: GitHub Actions → Publish Game Package → game_id `com.warp.riftsurvivors`, version `1.0.0`.

## WarpGameSDK
Лучший результат и настройки звука сохраняются через SDK. При запуске вне платформы игра использует localStorage как fallback.
