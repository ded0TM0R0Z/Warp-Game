# Rift Survivors

Мрачный 2D survival roguelite на Phaser 3.90.0. Горизонтальная ориентация, управление виртуальным стиком, автоматическая стрельба, офлайн-запуск.

## Основные механики
- Бесконечные процедурные области с тремя визуальными биомами: зелёные руины, пепельные пустоши и заражённые разломом земли.
- Шесть типов обычных противников: слизни, скелеты, громилы, призрачные охотники, бронированные жуки и дальнобойные культисты.
- Особые атаки противников: рывки, таран, ударная волна и магические снаряды с возможностью уклониться.
- Три босса с отдельными наборами атак: размеченный взрыв Разлома, костяные шипы и землетрясение Колосса.
- Три развиваемых навыка: Дух ветра, Земляной разлом и Цепная молния; Ветер можно эволюционировать в Грозовую корону.
- Критические попадания и отдельные улучшения шанса/множителя критического урона.
- У каждого босса есть вторая, ускоренная фаза ярости при низком здоровье.
- Реликвии усиливают урон, зелья восстанавливают здоровье. Боссы гарантированно оставляют награду.
- Улучшения формируют разные сборки в каждом забеге.

## Управление
- Левый виртуальный стик — движение.
- Рыцарь автоматически атакует ближайшего противника.
- При повышении уровня выбери одно из трёх улучшений.
- Кнопка паузы находится в верхней части экрана.

## Сборка и публикация
Все зависимости и графические ресурсы входят в ZIP-пакет. Игра не требует сети после установки.
Пакет публикуется GitHub Actions из `games/com.warp.riftsurvivors/`. Версия manifest остаётся 1.1.0; новые пакеты обнаруживаются по SHA-256.

## WarpGameSDK
Лучший результат сохраняется через SDK. При запуске вне платформы используется localStorage как резервный вариант.
